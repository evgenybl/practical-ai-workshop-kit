# The case, as plain files

These files hold the same case as the workbook: print the thread and the policy to keep them in view during the session, or attach them to an assistant. Everything in them is invented. The business, the people and the customers are invented, and any resemblance of a name to a real business or person is a coincidence.

| File | What it is |
|---|---|
| `customer-thread.txt` | The e-mail thread: five messages over nine days |
| `returns-policy.txt` | The supplier's returns and credits policy |
| `orders.csv` | The orders table, thirty rows; it opens in any spreadsheet |
| `snippets.txt` | The eight snippets of exercise 4 |

They are generated from `workbook/case-data.js` by the kit's build script, so they always match the workbook. Do not edit them here: a change belongs in the data file.
